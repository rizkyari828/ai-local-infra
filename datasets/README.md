# Learning datasets

This directory defines formats; it does not train models. Positive candidates must be accepted, reviewed, tested where relevant, and explicitly consented by the source project. Prefer references or sanitized excerpts over copied source. Proprietary code must remain project-isolated unless an authorized reviewer explicitly marks a sanitized example shareable.

Rejected or erroneous outputs belong in a separate ignored stream for evaluation/debugging and must never be silently relabeled as positive data. Runtime files under `accepted/` and `rejected/` are ignored; only schemas and deliberately curated fixtures are versioned.
